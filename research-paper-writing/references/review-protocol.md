# 逐段与整稿审查

## 高优先级｜正文与附录的抽象层级控制（写作与审稿均必须执行）

**核心定位：正文以科学问题、研究洞察、关键理论关系、机制与贡献的因果链为主，工程实现允许出现，但绝不能成为叙事焦点。** 学术层级按科学贡献和理解必要性分配篇幅，而非按代码复杂度或实现步骤多少分配篇幅；不能以增加公式和模块数量制造“高级感”。

- **工程操作可以有，但必须服务核心机制。** Padding、cropping、tensor reshaping、数据格式转换、循环位移的具体序列、数值容差和辅助接口等，默认放在 Implementation Details / Appendix。不要为了“完整”在 Methodology 主线逐步展开，更不要把辅助操作包装成独立的理论创新。
- **正文保留条件从严。** 只有删去某项操作会妨碍理解核心创新、改变关键数学关系的含义、无法识别必要的算法接口或误解重要前提时，正文才以一句简要作用说明或最小必要公式保留；优先说明“为何需要以及改变了什么”，不介绍 padding 尺寸、变换步骤、调用顺序等次要实现流程。核心机制若恰好由某种操作定义，可保留抽象算子式，具体执行仍交给附录。
- **附录承担复现责任。** 将数据预处理、边界处理、超参数、停止条件、精确相位规则和代码级流程等下沉至附录或正式复现材料；正文使用准确的概念和简洁引用，避免散落大量工程细节。不能因追求正文美感而隐去影响算法正确性、实验公平性或关键主张成立范围的事实。
- **编辑时执行减法测试。** 每准备在正文新增工程性文字、符号、公式或独立段落，先问：删除它是否损害核心思想的理解或技术准确性？若否，删去或移至附录。审稿时也按此标准识别“工程细节喧宾夺主”，不得要求作者把附录中的非关键操作反向搬进正文。

**最终验收：读完 Methodology，读者应先记住论文提出的科学思想和关键机制，而不是 padding、cropping 或若干辅助操作。** 此原则与技术真实性、必要的复现信息并行，不能用作掩盖真实实现或实验协议的理由。

## 高优先级｜实验结果优势的有力呈现（写作与审稿均必须执行）

**默认采用优势鲜明、富有说服力的结果叙事，而非平淡、克制到掩盖真实领先程度的记录式表达。** 实验章节的职责不仅是报告数字，更要让读者直接感受到方法在当前可验证任务和对比范围内的突出表现、领先幅度与科学意义。写作时主动寻找最强且真实的证据，优先组织成“关键对比→明确领先→核心机制所解释的收益”的论证。对已被证据充分支持的优势，应果断使用强有力且具体的措辞，不主动把“明显领先”弱化为“competitive”或“promising”。

- **定量结果突出领先地位。** 明确写出 best / highest / lowest / outperforms all compared methods / establishes the strongest result 等可核实结论；对多个指标同时领先、绝大多数设置第一、特定条件下领先幅度突出等事实主动强调。若某些设置达到较大领先幅度，可使用 substantial gains、particularly pronounced improvements、a clear advantage 等，不必逐项罗列全部差值；但不得把局部显著优势扩展为全部设置均大幅领先。
- **定性图像突出独有表现。** 结合原图准确抓取细小结构、轮廓、色彩、残余纹理等视觉证据；适宜时以“其他方法要么残留干扰、要么破坏目标结构；本文方法同时实现两项要求”构成鲜明对照。图像确实支持时允许使用 only、uniquely、stands out、all competing methods fall short 等有力度表达；不可在未经逐项核验时断言唯一、彻底、完美或所有方法失败。
- **结果描述以科学贡献而非形容词堆砌为重。** 强调这种领先解决了何种重要矛盾、同时保持了哪些难以兼顾的性质，并与 Introduction 和 Method 的核心贡献呼应。优先简洁的两三句话表达有力结论，避免逐个报数、平均语气对待所有方法、无谓自我贬低或因过度谨慎削弱明确的实验事实。
- **审稿质疑不是自动降调的理由。** 遇到有证据的强表达，先核实其量词、对比范围、指标方向、数值和图片事实；确认成立则保留锋芒，而不是为了“安全”改成平淡说法。若强表述无法由结果支持，应缩小适用范围、给出具体条件或改用正确的结果，而非虚构数据、夸大统计显著性、隐去反例或修改实验配置。

**验收标准：读完 Experiments，读者不仅知道我们得了多少分，还能立即说清“我们在哪些方面明显领先、领先意味着什么、哪幅图或哪张表能直接证明”。** 优势导向与可核验证据并重，强力度不等于无条件绝对化。

## 逐段门槛

给每段稳定编号。完成一段即做作者自审，再将段落、必要上下文与证据包分别交给模拟领域审稿人及 AI 辅助审稿视角。两种审稿分别记录结论，彼此不读意见。若只能模拟，就标明执行方式。完整论文可分批组织审查，批内仍要逐段判定并保存可追踪结果。

- **作者自审** — 用一句话概括该段任务。逐句标出主张和支撑位置，检查事实、符号、量词、前提、限定及与相邻段的承接。比较 Humanizer 改写前后的主张、限定与证据锚点。出现实质漂移时恢复准确表述并复审。
- **领域审稿** — 独立复述中心主张，检查理论、最接近工作的差异、设计的必要性、证据、反例和替代解释。先给最强的合理反对意见，再按量表评分。
- **AI 辅助审稿** — 从论文中抽取每个主张并定位证据，检查未定义名词、符号漂移、范围放大、数字不一致、引文无法核实、段落依赖和缺失协议。尝试仅凭文本重建机制与主要实验。

### 图像与图文对应的事实核验（中等优先级审稿原则）

审查论文图像、示意图、可视化和实验对照时，先确认**展示结构**，再解释**科学含义**。此原则属于常规证据核验，不提升为高于理论正确性、实验证据或写作核心目标的总原则。

- **先辨认布局**：结合原图、图注、子图标注和必要的绘图源码，辨明单图左右拼接、分割线、局部放大、蒙版覆盖、并列输入/输出、多时刻帧与不同物体。不能把同一场景左右不同位置的内容自动当成同一对象的前后变化。例如限速“60”标志中左右显示的“6”和“0”，不能仅凭拼接图断言算法将“6”变成“0”。
- **区分事实与推断**：明确区分“图上能看到什么”“论文声称什么”“实验记录或代码证实什么”“审稿者推测什么”。视觉观察不能直接推出因果关系；缺少配对、原图或生成记录时标记“待核实”，而不是描述成已确认的算法缺陷。
- **交叉验证再定级**：提出图像失真、边缘破坏、标注错误或实验不公平等批评前，优先核对原始图、论文图注、相关正文和配置记录。若正文说法与图示可能冲突，精确指出冲突与核查路径；不要擅自归罪于图片、算法或作者。
- **修正审稿误判**：若发现误读，立即撤回由其派生的负面评价与严重度，不为了维持审稿结论而另行推测。其他理论、消融、公式和引用的批评也应采用同样的“可定位证据—结论范围—未核实项”纪律。

| 维度 | 能给 3 或 4 分的可检验表现 |
|---|---|
| 新颖性 | 可指出相对最接近方法的实质变化，准确区分既有工具、组合与新贡献 |
| 数学与技术严密性 | 定义域、假设、量词和推导可逐步复核，结论范围正确，目标与实现一致或交代差异 |
| 证据与事实忠实度 | 每个事实可追溯，措辞与证据强度相符，精确保留数值、协议、引用和状态 |
| 清晰度 | 可复述主张及其依据，术语一致，读者知道此段为何出现在这里 |
| 可复现性 | 可定位实现、数据、配置、关键步骤和未公开或未验证材料的范围 |
| 相关工作 | 核实最接近工作的设定及差异，所有比较可核证 |
| 实验设计 | 对照、公平性、机制指标、消融、不确定性及结果解释与主张对应 |

统一量表。**0** 为缺失或矛盾，**1** 为实质错误，**2** 为需实质补充，**3** 为有充分依据且仅余非阻断的小修，**4** 为可独立核查且表述准确。局部不适用填 N/A 并说明，整稿七项都需要判断，纯理论或无实验的稿件在证据维度说明适用的验证方式。每种视角的适用维度均须至少 3 分，数学与技术严密性、证据与事实忠实度适用时须 4 分。平均分不能抵消失败项。

阻断项包括反例击中关键主张、不可成立的推导、数据或引文失实、关键新颖性无来源支撑、证据与主张的范围不符、关键对照不公平。每个问题填写“段/式/表位置、实际疑点、严重度、为什么影响结论、最小修复、复核依据”。修订后重跑三种视角和受影响段落。仅润色不能解决证据问题。缺实验时可收窄至有依据的条件结论，或保留草稿和阻断状态。

## 整稿投稿前审查

1. 冻结候选版本，准备稿件、附录、材料版本、主要证据、实现入口与目标会议现行政策。模拟独立审稿优先使用专用上下文，仅共享必要资料；保护未公开稿件和身份。
2. 模拟领域审稿人先写无作者提示的论文摘要，再给最强反对意见、实质优点、关键问题和七项评分。复算一条最关键推导，复核最接近方法与一个关键实验。
3. 模拟 AI 辅助审稿另起一份意见，从摘要和引言逆向核对正文、附录、代码及证据。检查全局自洽性、训练/推理口径、声明和复现路径。核对主指标与比较口径的选择依据，以及反例和重要局限能否追溯。独立打分并为每项主要问题给位置。
4. 合并意见形成修订表，优先处理阻断，再处理主要、次要问题。冲突意见回到原始证据。选择补证明、收窄结论、改实验或改写对应段落。需要新实验时给出预期支持、反驳及无法判定的结果。
5. 重新检查修改点与依赖内容。通过条件为七项审查门槛满足、阻断为零、关键主张全部可追溯、正文与补充材料一致。保留风险清单和已通过的版本；证据未齐时写明哪些部分可用、哪些主张阻断投稿准备。

```text
版本与审查范围：
审查角色与独立性：
主张复述：
位置｜维度｜严重度｜证据或反例｜分数｜修订与复核｜状态
最高优先级待办：
结论（通过/草稿可用但有阻断/需要补证据）：
```

评分供诊断。不能确保录用或任何审稿人、AI 打高分。以可独立验证的贡献为目标，禁止针对评审模型插入暗示指令、隐藏文本或其他操纵评分的内容。
